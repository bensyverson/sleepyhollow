# Background

Who this work is for, the people behind it, and the constraints that come with them. Context for weighing a decision, not for writing code — what the software *is* belongs in the README and the head of `AGENTS.md`. List this file from that head so every session can find it.

- **It holds current state: rewrite it, never append.** When a fact changes, edit the sentence that holds it — the dated `project/` doc keeps the history.
- **Every number, date and name appears once**, and links the dated document it came from.
- **Delete a section with nothing to say.** A short file that is true beats a complete one that is stale.
